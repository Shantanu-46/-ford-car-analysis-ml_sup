🚗 Ford Car Price Prediction

A Machine Learning project focused on analyzing Ford car data and predicting car prices using Linear Regression. The project includes data exploration, preprocessing, feature encoding, scaling, and model evaluation.

📌 Project Overview

This project analyzes a Ford car dataset to understand important patterns and factors affecting car prices. Various data preprocessing and feature engineering techniques were applied before building a Linear Regression model.

🔍 Key Steps

* Exploratory Data Analysis (EDA)
* Data cleaning and preprocessing
* One-Hot Encoding
* Label Encoding
* Embedding
* Feature Scaling
* Train-Test Split
* Linear Regression Model
* Model Evaluation

🤖 Machine Learning Model

Algorithm: Linear Regression

The model achieved approximately 83% accuracy, demonstrating good predictive performance on the dataset.

🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

📊 Workflow

Dataset → EDA → Data Preprocessing → Encoding → Feature Scaling → Train/Test Split → Linear Regression → Model Evaluation

🎯 Objective

The main objective of this project is to apply the complete Machine Learning workflow to real-world automotive data and build a model capable of predicting Ford car prices.
